Privacy Policy

Last updated: 1 October 2026

This privacy policy covers the personal application rclone-sync ("the application"), which uses the Google Drive API to synchronise files between one computer and one Google Drive account.

1. Who runs this application

The application is a private, single-user tool operated by its owner for their own use (one user: the Google account holder who authorised it). It is not distributed, published in any app store, or made available to third parties.

2. What data is accessed

  • Google Drive files and metadata belonging to the authorising user, accessed through the Google Drive API — solely to list, download and upload files for synchronisation.
  • OAuth credentials (access and refresh tokens) issued by Google to this application. They are stored locally in the user's own rclone configuration file on the user's own computer, protected by the operating system's file permissions.

3. How data is used

Data is used only to perform the file synchronisation described above. File contents are transferred between the user's computer and the user's own Google Drive. No file content is analysed, indexed, profiled or used for any other purpose.

4. Data sharing

No data is transmitted to any third party, server or service other than Google Drive itself (Google's Privacy Policy applies to that transfer). The application collects no analytics, telemetry or advertising identifiers.

5. Data storage and retention

No copy of the user's files is stored anywhere except the user's own computer and the user's own Google Drive. Synchronisation logs are written locally on the user's computer and contain file names and transfer results only. Deleting the application's rclone configuration removes the locally stored tokens.

6. Revoking access

The user can revoke this application's access to their Google account at any time at myaccount.google.com/permissions, which immediately invalidates its stored tokens.

7. Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children

The application is not directed at children and is not used by anyone other than its single owner.

9. Changes

Any change to this policy will be published on this page with an updated date.
